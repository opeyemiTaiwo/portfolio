# portfolio

Personal website of Opeyemi Adeniran: AI researcher at Morgan State University, founder of She Model Tech, and founder and lead director of Morgan TechFest.

A static site with no build step:

- `index.html`: page content
- `assets/css/style.css`: styles, including light and dark themes
- `assets/img/`: headshot and favicon

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.
